# Pressure plates

A terracotta pressure plate works like a stone pressure plate. It turns on while a player or mob stands on it.

<ShapeRecipe shape="pressure_plate" />

## Behavior

| | |
| --- | --- |
| Signal | Strength 15 while something is on it |
| Triggered by | Players and mobs. Dropped items, arrows, boats and minecarts do not trigger it |
| Placement | On top of a block, like vanilla pressure plates |
| Breaking | Breaks in a moment with any tool or by hand, and always drops itself |
| Pistons | Pushing it breaks it and drops it as an item |
| Sounds | Stone pressure plate clicks |

::: tip
To detect dropped items as well as mobs, use a wooden pressure plate or a weighted pressure plate instead.
:::

Every terracotta pressure plate is in the vanilla `#minecraft:pressure_plates` tag. See [Tags](../reference/tags).
