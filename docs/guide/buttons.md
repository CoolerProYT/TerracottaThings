# Buttons

A terracotta button works like a stone button. Press it and it sends a redstone signal for **1 second**, then releases with a stone click.

<ShapeRecipe shape="button" />

## Behavior

| | |
| --- | --- |
| Signal | Strength 15 for 1 second (20 ticks) |
| Pressed by | Players, and arrows or tridents that hit it (it stays pressed while the arrow is stuck in it) |
| Placement | On any face of a block, like vanilla buttons |
| Breaking | Breaks in a moment with any tool or by hand, and always drops itself |
| Pistons | Pushing it breaks it and drops it as an item |
| Sounds | Stone button clicks |

::: info Unlike stone buttons
Vanilla stone buttons ignore arrows. Terracotta buttons are pressed by arrows, like wooden buttons, which makes them handy as shooting targets.
:::

Every terracotta button is in the vanilla `#minecraft:buttons` tag. See [Tags](../reference/tags).
