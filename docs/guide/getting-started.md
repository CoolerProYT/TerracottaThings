# Getting started

Terracotta Things adds building and redstone blocks made from terracotta. Each of the 33 terracotta blocks in the game gets five new shapes:

| Shape | Made from | Per recipe |
| --- | --- | --- |
| [Buttons](./buttons) | 1 terracotta | 1 |
| [Pressure plates](./pressure-plates) | 2 terracotta | 1 |
| [Stairs](./stairs) | 6 terracotta | 4 |
| [Slabs](./slabs) | 3 terracotta | 6 |
| [Walls](./walls) | 6 terracotta | 6 |

The 33 terracotta blocks are plain terracotta, the 16 dyed colors and the 16 glazed colors, so the mod adds 165 blocks in total.

## Install

1. Install [Fabric](https://fabricmc.net/) with [Fabric API](https://modrinth.com/mod/fabric-api), or [NeoForge](https://neoforged.net/), for Minecraft **26.3**.
2. Put the Terracotta Things jar in your `mods` folder.

The mod adds blocks, so it has to be installed on the server and on every client that joins.

## Finding the blocks

In Creative mode, every block is in the **Terracotta Things** tab. It lists all buttons first, then pressure plates, stairs, slabs and walls. Within each shape, plain terracotta comes first, then the dyed colors, then the glazed colors.
