# Terracotta Things

Adds functional building block variants for every terracotta and glazed terracotta color in Minecraft. All blocks reuse vanilla textures — no resource pack needed.

## Blocks

Each of the 17 terracotta colors (plain + 16 dyed) and 16 glazed terracotta colors gets the following block variants:

| Type | Count |
|---|---|
| Buttons | 17 terracotta + 16 glazed = 33 |
| Pressure Plates | 17 + 16 = 33 |
| Stairs | 17 + 16 = 33 |
| Slabs | 17 + 16 = 33 |
| Walls | 17 + 16 = 33 |
| **Total** | **165 blocks** |

All terracotta walls connect to each other and to vanilla walls.

## Creative Tab

All blocks are grouped in the **Terracotta Things** creative tab, ordered by type (buttons → pressure plates → stairs → slabs → walls), with plain terracotta variants first and glazed variants after in each group.

## Mod Loaders

- **NeoForge**
- **Fabric**

- NeoForge: [NeoForge](https://neoforged.net/)
